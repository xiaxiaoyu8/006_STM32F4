# HC-05经典蓝牙模块

**需要确认手机是否支持经典蓝牙**
是一款基于Bluetooth Specification V2.0带EDR蓝牙协议的**主从一体蓝牙串口通信模块**。
工作在2.4GHz ISM频段，采用GFSK调制，最大发射功率为4dBm，接收灵敏度-85dBm，通信距离约10米。
模块核心采用CSR的BC417芯片，支持AT指令修改设备参数。

### 🔌 HC-05引脚定义与接线

HC-05模块通常有6个引脚，其定义和功能如下表所示：

| 引脚名称 | 功能说明 |
| **VCC** | 模块供电正极 (**3.6V-6V**)，通常接5V |
| **GND** | 模块供电负极，接地 |
| **TXD** | **串行数据输出**，接单片机/开发板的RXD |
| **RXD** | **串行数据输入**，接单片机/开发板的TXD |
| **KEY** (或EN) | 用于**切换AT命令模式** (高电平有效) |
| **STATE** | **状态指示输出**，连接时输出高电平，未连接时输出低电平 |

#### 常用接线场景

*   **与Arduino等开发板连接**
    这是最常见的用法，实现单片机与蓝牙设备的无线串口通信。
    *   HC-05 VCC → 开发板 **5V**
    *   HC-05 GND → 开发板 **GND**
    *   HC-05 TXD → 开发板 **引脚2** (SoftwareSerial的RX)
    *   HC-05 RXD → 开发板 **引脚3** (SoftwareSerial的TX)

*   **与USB转TTL模块连接（用于配置）**
    通过电脑的串口调试助手给HC-05发送AT指令时，需要这样连接。
    *   HC-05 VCC → USB转TTL **5V**
    *   HC-05 GND → USB转TTL **GND**
    *   HC-05 TXD → USB转TTL **RXD**
    *   HC-05 RXD → USB转TTL **TXD**
    *   HC-05 KEY → USB转TTL **3.3V** (如需进入AT模式)

### ⚙️ AT指令模式与配置

AT指令模式用于查询和配置蓝牙模块的各项参数，如名称、波特率、配对密码等。

#### 进入AT模式的方法

1.  **按键法（常用）**：在给模块**通电之前**，先按住模块上的**小黑点按键**不松开，然后上电。此时模块上的**LED指示灯变为慢闪（约1秒1次）**，表示已进入AT模式。
2.  **KEY引脚控制法**：将KEY引脚**接高电平（3.3V）**，然后给模块上电，同样可以进入AT模式。

> 在AT模式下，模块的**默认通信波特率通常是38400**。请确保你的串口调试工具也设置为此波特率、8位数据位、1位停止位、无校验位。

#### 常用AT指令

在串口调试助手中发送以下指令（注意每条指令后需加上`\r\n`或勾选"发送新行"）：

| 指令 | 功能 | 示例响应 |
| :--- | :--- | :--- |
| `AT` | 测试连接 | `OK` |
| `AT+NAME?` 或 `AT+NAME=<name>` | 查询/设置设备名称 | `+NAME:<name>` |
| `AT+UART?` 或 `AT+UART=<baud,stop,parity>` | 查询/设置串口参数 | `OK` (例如设置为9600: `AT+UART=9600,0,0`) |
| `AT+ROLE?` 或 `AT+ROLE=<0/1>` | 查询/设置主从角色 (0从机,1主机) | `+ROLE:<0/1>` |
| `AT+PSWD?` 或 `AT+PSWD=<pin>` | 查询/设置配对密码 | `+PSWD:<pin>` (默认1234) |
| `AT+ORGL` | 恢复出厂设置 | `OK` |

### 💻 基础使用示例

配置完成后，断电再重新上电，模块指示灯会**快闪**，进入可配对状态。此时用手机搜索并连接名为"HC-05"的设备，输入配对码（默认1234）即可。

连接成功后，你可以编写程序让单片机通过蓝牙与手机通信。下面是一个Arduino的简单"回声"程序示例：当手机发送数据给HC-05时，Arduino会通过HC-05将数据原样发回手机。

```c
#include <SoftwareSerial.h>
// Pin2为RX，接HC05的TXD; Pin3为TX，接HC05的RXD
SoftwareSerial BT(2, 3); 
char val;

void setup() {
  Serial.begin(9600);
  Serial.println("BT is ready!");
  BT.begin(9600); // 确保此处的波特率与你用AT指令设置的波特率一致
}

void loop() {
  // 将来自电脑串口监视器的数据发送给手机
  if (Serial.available()) {
    val = Serial.read();
    BT.print(val);
  }
  // 将来自手机的数据发送给电脑串口监视器
  if (BT.available()) {
    val = BT.read();
    Serial.print(val);
  }
}
```

### 💡 注意事项与常见问题

*   **接线交叉**：牢记 **TXD 与 RXD 需要交叉连接**，即模块的TXD接MCU的RXD，模块的RXD接MCU的TXD。
*   **波特率匹配**：确保在**透传模式**下，单片机程序初始化蓝牙串口的波特率与用`AT+UART`指令设置的波特率一致。在**AT模式**下，则使用固定的38400（或按手册说明）波特率。
*   **供电充足**：为模块提供稳定且足够的电源（5V典型），避免因供电不足导致工作不稳定。
*   **指令格式**：发送AT指令时，**务必在指令末尾加上回车换行 (`\r\n`)**，或在串口调试助手中勾选"发送新行"，否则模块无法识别。
